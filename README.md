# yockers-svg-animation
<p>SVG Animation Showcase.</p>

<p>One-page showcase featuring 4 web micro-animations. SVG attributes are animated using CSS transitions.</p>
<br>
<p>CSS animation techniques demonstrated:
  <ol>
    <li>hover transition</li>
    <li>spinning loader</li>
    <li>self-drawing line</li>
    <li>fade-up entrance</li>
  </ol>
</p>
<br>
<p>Key Objectives:
  <ul>
    <li>Animate elements using @keyframe rules.</li>
    <li>Rotation and Scaling use transform + transform-origin.</li>
    <li>Animate (draw) lines using the SVG line drawing trick: stroke-dasharray + stroke-dashoffset.</li>
    <li>Prefers-reduced-motion is functional.</li>
  <ul>
</p>
